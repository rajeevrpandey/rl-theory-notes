# RL Fundamentals

This section introduces the basic ideas of Reinforcement Learning from the ground up. It starts with the question of how RL differs from standard supervised learning, then builds the core vocabulary: agents, environments, states, actions, rewards, policies, models, and value functions.

The goal is to develop the intuition needed before moving to Markov Decision Processes, Bellman equations, exploration methods, regret analysis, and more advanced RL theory.
