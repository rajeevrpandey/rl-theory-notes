# What makes Reinforcement Learning different from normal Machine Learning?

## Core idea

In supervised learning, the model learns from labeled examples.

In reinforcement learning, an agent learns by interacting with an environment, taking actions, receiving rewards, and improving its behavior over time.

## Key ingredients

- Agent
- Environment
- State
- Action
- Reward
- Policy
- Return

## Short intuition

Supervised learning asks:

> What is the correct answer for this input?

Reinforcement learning asks:

> What action should I take now so that my long-term reward becomes large?
